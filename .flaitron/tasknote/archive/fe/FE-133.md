**Implementation Notes:**

- Extended the three existing gate blocks. One local rule, `flaitron/no-restricted-import-expressions`, visits `ImportExpression` and runs the same pattern objects core uses: `ignore` with `allowRelativePaths` for `node:*`, and the relative regex with the `u` flag when `caseSensitive` is set. A static template literal counts as a static specifier. A computed specifier is an error, with the message for that block's section.
- `ignore` is a direct devDependency (`^5.3.2`). The config must not import eslint's transitive copy.
- The test helper checks both rule ids. Each static fixture is also checked as `import()`. The live `TaskDetailPanel` module is linted through the same helper.
- Node-only → `src/ui` and the layout sketch stay deferred, as in FE-131. `TSImportType` (`import('…')` in type position) is a different node; filed FE-134 rather than folded in.
