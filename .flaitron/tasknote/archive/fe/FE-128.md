# FE-128 | viz-host-pin

[← PLAN.md](../PLAN.md) · 🟢 In progress · 🔗 [[FE-127.3]]

## 🎯 Goal

Make the viz dev server bind loopback only even when started with `vite --host`, so the page, `/src/*`, `/@fs/` and HMR are unreachable from the network, and retire SECURITY.md's "do not run with `--host`" caveat.

## ✅ Acceptance

- [x] `npm --prefix viz run dev -- --host` listens on loopback only — `lsof -nP -iTCP:5120 -sTCP:LISTEN` shows `127.0.0.1` (or `::1`), not `*`; `curl` to the LAN address is refused
- [x] Plain `npm --prefix viz run dev` still serves at `http://localhost:5120` — `curl -s -o /dev/null -w '%{http_code}' http://localhost:5120/` → 200
- [x] SECURITY.md §Visualizer no longer says `--host` exposes the port or to avoid it — `! grep -n -e '--host' SECURITY.md` (or the surviving mention states the loopback pin)
