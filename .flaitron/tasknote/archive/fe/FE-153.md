**Implementation Notes:**

- `skeletonOwedRef`: the skeleton load records the scopes it raised for; each settling load for the current project deletes the scopes it is still latest for; emptying the set lowers `loading`. Replaces "only the skeleton load lowers it", which stranded the flag when a full refresh superseded the initial load.
- `lastPlanArchiveRef`: `{ project, md }` saved when a plan slice commits with a fresh archive body. The archive fetch's rejection and body-read failure are both caught, and a failure reparses fresh PLAN.md against the cached body (empty when none yet, which keeps the prior first-load behavior).
- 4 new tests: 2 for a later archive failure (non-OK; rejected — other slices still commit), 2 for the loading flag (a full refresh supersedes the initial load; a scoped refresh outrunning it keeps the flag raised — a regression guard that passes on both old and new code).
