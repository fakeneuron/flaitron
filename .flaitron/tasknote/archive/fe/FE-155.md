# FE-155 | time-out-board-fetches

[← PLAN.md](../PLAN.md) · 🟢 In progress · 🔗 [[FE-153]]

## 🎯 Goal

Add a timeout to required board-load fetches so a hung request surfaces as a scope error instead of holding the skeleton.

## ✅ Acceptance

- [x] A required fetch that does not settle within `BOARD_FETCH_TIMEOUT_MS` aborts, lowers the skeleton, and records the timeout on that scope only — `npm --prefix viz test -- src/ui/useProjectData.test.ts`
- [x] Sibling scopes whose fetches succeed in that same load still commit — `npm --prefix viz test -- src/ui/useProjectData.test.ts`
- [x] A hung `/api/plan-archive` fetch aborts on the same deadline, leaves `error` null, and still commits PLAN.md — `npm --prefix viz test -- src/ui/useProjectData.test.ts`
- [x] A non-timeout rejection of a required fetch still errors every requested scope — `npm --prefix viz test -- src/ui/useProjectData.test.ts`
- [x] The changed hook typechecks and lints — `npm --prefix viz run typecheck` and `npm --prefix viz run lint`

## 🧩 Subtasks

- [x] Abort each required board fetch with `AbortSignal.timeout` and pin a timeout to that scope
- [x] Give the optional `/api/plan-archive` fetch the same deadline without a scope error
- [x] Cover a hung required fetch and a hung archive fetch in the hook tests
